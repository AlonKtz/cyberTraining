Web Security Training

Interactive labs for SQL Injection, XSS, CSRF, and Password Storage. Practice attacks on vulnerable endpoints, then see how to fix them.

💡 How to use these labs Each lab has two sides: a Vulnerable panel where you can practise the attack, and a Secure panel showing the correct implementation. Everything runs in your browser — no server required.
Lab 1

SQL Injection

Bypass login with crafted SQL. Learn why string concatenation is dangerous and how parameterized queries fix it.
Lab 2

Cross-Site Scripting

Inject JavaScript into a comment board. See how unsanitized output leads to script execution and how escaping stops it.
Lab 3

CSRF

Simulate a forged bank transfer from a malicious page. Understand how CSRF tokens and origin checks protect users.
Lab 4

Password Storage

Compare plain-text vs bcrypt hashed storage. Trigger a simulated DB leak to see why hashing matters.

Key Principle

🚫 NEVER TRUST USER INPUT Every vulnerability in these labs traces back to trusting data from the outside world. Validate, sanitize, escape, and parameterize — always.
